# Your notes shouldn't be dead files.

## AKASHA thinks while you dream.

Akasha is a **local-first, concept-oriented operating system**.

It begins with a simple observation:

> **Human beings rarely think in files.**
>
> We think in **concepts**.

A remembered sentence.

A quotation.

A place on a map.

A field observation.

A scientific hypothesis.

A recipe.

A story.

Modern software organizes information into documents, records, tables, and pages.

Akasha organizes **meaning**.

# Install in minutes

Download the seed from [Releases](https://github.com/akashicmaster/AkashaSeeds/releases), then:

```bash
mkdir akasha
cd akasha

python akasha_seeds_seeds12.py
```

The seed expands into a complete local semantic environment.

From the second launch onward:

```bash
python akasha.py
```

No cloud.

No mandatory infrastructure.

Runs on Linux, macOS, Windows, Raspberry Pi—even iPad.

# Why Akasha?

Unlike traditional software, Akasha treats **concepts** as the primary unit rather than files, tables, or documents.

Its architecture is built around a few simple principles:

- 🧠 Concepts before implementation
- ⚛️ Three primitives — Atom, Link, and overlapping Set — beneath everything else
- 🔗 Semantic graphs instead of isolated documents
- 🧩 Plug-in Concept Models
- 🏗 World, Workbench, and Workflow on the same substrate as the knowledge they act on
- 🤝 Humans, LLMs, programs, and sensors as peers in one semantic world
- 🔌 Native MCP integration
- 🌍 Browser portals generated from the same semantic space
- 🌱 Local-first, and able to keep working when capabilities retreat
- 📦 Single-file Seeds deployment
- 🪶 MIT licensed

One graph.

One memory substrate.

Many worlds.

The ideas are older than the code. Most of them were formed roughly thirty years ago in knowledge engineering; the 2026 implementation is the point at which hardware, networks, and LLMs let them run.

# The journey

Akasha is not trying to become another note-taking application.

Nor another database.

Nor another AI framework.

It is an experiment in treating **concepts as computational objects**.

The substrate has been built, and it has survived reality.

Now it is being used—

by people,

by LLMs,

by a machine learning plants inside a semantic world,

and eventually,

by the physical world itself.

The expedition is only beginning.
